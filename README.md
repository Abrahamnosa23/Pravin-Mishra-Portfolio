# DMI Portfolio Website (Static HTML/CSS)

This repository contains a clean, professional-looking **static portfolio website** used in **DevOps Micro Internship (DMI)** Week 1 to practice:
- Linux basics
- Nginx hosting
- Deployment proof / ownership
- Production-style checks

✅ Students deploy this website on an Ubuntu VM using Nginx and keep it live for 24 hours.

---

## Who is this for?
- DMI students (beginner → intermediate)
- Anyone learning how to host a static site with Nginx on Linux

---

## What you will build
A portfolio-style website hosted on:
- **Ubuntu VM**
- **Nginx**
- Accessible via: `http://<public-ip>`

## Dynamic deployment date

The footer date is generated by the inline JavaScript in `index.html`. When the page
loads, it uses the browser's current date and formats it as `day month year`, so the
date stays current without manually editing the footer for each deployment. The
copyright year is generated by the same script.

Because this is a static site with no build pipeline, the displayed date is the
visitor's current browser date rather than a server-recorded deployment timestamp.
